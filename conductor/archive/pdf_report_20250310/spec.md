# Track pdf_report_20250310: Automated PDF Report Generation

## Goal
Implement a professional PDF report generation feature that compiles mission parameters, PINN optimization results, and trajectory plots into a single, distributable document.

## Scope
- Selection and integration of a PDF generation library (e.g., `fpdf2`).
- Creation of a structured report template (Header, Mission Specs, Optimization Results, Plots, Footer).
- Integration with the existing `run_demo.py` CLI tool.
- Integration with the Streamlit `app.py` dashboard for direct report downloads.

## Technical Details
- **Library**: `fpdf2` for Python.
- **Data Source**: `SpacecraftConfig` and `OptimizationResult` objects.
- **Images**: PNG files generated by `matplotlib` and `plotly` (static exports).
- **Location**: Generated reports saved in `outputs/reports/`.

## Acceptance Criteria
- [ ] PDF report contains correct mission metadata (Name, Altitude, Mass, etc.).
- [ ] PDF report displays final ΔV optimization results and lifetime predictions.
- [ ] Trajectory and Loss plots are correctly embedded in the PDF.
- [ ] Users can trigger PDF generation via `run_demo.py`.
- [ ] Users can download the PDF directly from the Streamlit dashboard.
- [ ] Code coverage for the reporting module is >80%.
